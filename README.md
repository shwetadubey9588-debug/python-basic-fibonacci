# Fibonacci Number Calculator

A simple Python program that calculates the **Fibonacci number** for a given input. This project demonstrates the basic use of variables, loops, and arithmetic operations in Python.

## 📌 Project Description

This repository contains `fibonacci.py`, a Python program that calculates the Fibonacci value at a specified position in the Fibonacci sequence.

The Fibonacci sequence starts with:

`0, 1, 1, 2, 3, 5, 8, 13, ...`

Each number is calculated by adding the two preceding numbers.

## ✨ Features

* Calculates the Fibonacci number for a given position.
* Simple and beginner-friendly Python implementation.
* Uses basic Python programming concepts.
* Easy to run and understand.

## 📋 Requirements

* **Python 3.x**
* No external Python libraries are required.

## 💡 Example

For an input of:

```text
5
```

The Fibonacci value is:

```text
5
```

This is because the Fibonacci sequence is:

```text
0, 1, 1, 2, 3, 5
```
